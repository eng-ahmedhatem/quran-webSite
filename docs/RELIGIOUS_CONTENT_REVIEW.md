# بوابة المراجعة الشرعية للمحتوى

الحالة الحالية: **بانتظار اعتماد مراجع شرعي متخصص قبل الإطلاق العام**.

هذا الملف ليس فتوى ولا اعتمادًا للمحتوى. الغرض منه منع اعتبار سلامة الكود بديلًا عن المراجعة البشرية للنصوص والتخريج.

## نطاق المراجعة

- نصوص أذكار الصباح والمساء.
- أذكار النوم والاستيقاظ وما بعد الصلاة.
- أدعية السفر ودخول البيت والخروج منه ودخول المسجد والخروج منه.
- عدد مرات التكرار لكل ذكر.
- عناوين المصادر والتخريج المختصر الظاهر للمستخدم.
- أي نص ثابت أو مقتبس يظهر في الصفحة الرئيسية أو الإشعارات.
- التأكد من عدم تكرار البسملة أو حذف جزء من الآية عند تنسيق نص المصحف.

## قائمة التحقق

- [ ] مطابقة النص العربي حرفيًا لمصدر معتمد.
- [ ] مطابقة عدد التكرار للرواية المعتمدة.
- [ ] توثيق المصدر والحديث ودرجته عند الحاجة.
- [ ] فصل النص المأثور عن الإرشادات التوضيحية بوضوح.
- [ ] مراجعة علامات الوقف والتشكيل وعدم تغيير المعنى.
- [ ] مراجعة التصنيف الزمني والسياق لكل ذكر.
- [ ] اختبار عينة من نص المصحف مقابل مصحف المدينة المعتمد.
- [ ] اعتماد النسخة النهائية بعد كل تعديل لاحق في بيانات الأذكار.
